## Acceptance criteria

1. `research/raw/m054-style-read.json` cites the lines that carry the declarations it quotes, and each citation is checked against the current the current sheet rather than accepted because it was true before the token block moved them.
2. No quotation in the recording is reworded: the values it records are the values the sheet declares, and only the line numbers it points at move.
3. `scripts/visual-qa-style-read.test.mjs` passes including its three mutants, and the citation set is regenerated by a documented step rather than hand-edited line by line.

## Approach

The recording was captured once by M054's first task, and `scripts/visual-qa-style.test.mjs:9` states the rule it lives under: it "is read here and never edited". T002 then rewrote the stylesheet, so the citations it carries now point at lines the token block shifted — the values are unchanged, the line numbers are stale.

There is no `M054_CAPTURE` arm in any suite, so this is not a capture command: it is a re-derivation. Find every citation the recording states for the current sheet, locate the declaration it quotes in the current sheet, and move the line number to it. Prove each one: the quoted text must still be what that line declares. If a quotation no longer exists in the sheet, stop and report it — that is a value that moved, not a citation that slid, and it belongs to a decision rather than to an edit.
